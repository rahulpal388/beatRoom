# BeatRoom 🎵

BeatRoom is a web-based music application where users can browse and play songs through a clean and simple interface.  
This project was built to practice full-stack web development concepts such as UI design, state management, and backend API integration.

---

## Features

- Play and pause songs
- Browse songs and albums
- View song details
- Simple and responsive music player UI

---

## Tech Stack

**Frontend**
- React / Next.js
- TypeScript
- Tailwind CSS

**Backend**
- Node.js
- REST API

**Database**
- MongoDB

---

## Project Purpose

This project was created to practice:

- Building a full-stack application
- Managing application state
- Creating reusable UI components
- Designing APIs
- Handling media playback in the browser
